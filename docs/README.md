# 跨模块文档

`docs/` 只存放不能归属到单一源码包的内容：架构决策、跨模块设计、迁移计划、评审报告和历史任务记录。

单个包的功能、公开入口和实现细节请直接阅读该包目录下的 `README.md`；写作与放置规则见唯一标准：[DOCUMENTATION_STANDARD.md](DOCUMENTATION_STANDARD.md)。

现有入口：

- [arch/](arch/)：架构专题。
- [review/](review/)：架构评审资料。
- [plan/](plan/)：历史设计与迁移计划。
- [history/](history/README.md)：按日期归档的一次性任务方案、记录和验证结果。
