# 历史归档

本目录集中存放一次性任务、迁移、评审与验证记录。所有文件或目录名以 `YYYY-MM-DD` 开头的文档产物必须放在这里，而不应散落在 `docs/` 或模块目录中。

## 归档规则

- 目录使用 `YYYY-MM-DD-<topic>/`；同一任务的计划、评审、日志和测试报告保留在该目录内。
- 单文件历史记录使用 `YYYY-MM-DD-<topic>.md`。
- 当前且长期有效的模块说明应迁入对应源码目录的 README；跨模块稳定设计保留在 `docs/arch/` 等主题目录。
- 迁移时保留相对目录结构和文件名，避免破坏历史链接。

文档放置的完整规则见 [文档标准](../DOCUMENTATION_STANDARD.md)。
